# Current lesson: 2.1 Your first Flask route

**Out of scope:** Databases, authentication, deployment, and JavaScript. This course gets you to a small server-rendered Flask app running locally.

## Section 1: Python foundations for the web
**Start point:** Can open a terminal and run a `.py` file.
**End goal:** Can write functions that take arguments, return values, and use lists and dicts to shape data.

### 1.1 Variables, types, and running a script
**Start point:** Can run a `.py` file.
**End goal:** Writes a script that stores values in variables of the right type and prints a computed result.

### 1.2 Functions and return values
**Start point:** Can write and run a linear script.
**End goal:** Writes a function that takes parameters and returns a value, and calls it from another function.

### 1.3 Lists and dictionaries
**Start point:** Can write functions.
**End goal:** Builds and reads a list of dictionaries to represent a small collection of records.

## Section 2: A first Flask app
**Start point:** Can write Python functions that shape data with lists and dicts.
**End goal:** Runs a local Flask app with multiple routes that renders HTML from templates and handles a form submission.

### 2.1 Your first Flask route
**Start point:** Can write and run Python functions; Flask is installed.
**End goal:** Creates `app.py` with a Flask app and a `/` route that returns an HTML string, runs it with `flask run`, and views it in a browser.

### 2.2 Templates with Jinja
**Start point:** Has a running Flask app with one route.
**End goal:** Moves the HTML into a `templates/` file and renders it with `render_template`, passing in a variable.

### 2.3 Handling form input
**Start point:** Renders templates with Jinja.
**End goal:** Adds a route that accepts a POST form submission and shows the submitted value back to the user.
