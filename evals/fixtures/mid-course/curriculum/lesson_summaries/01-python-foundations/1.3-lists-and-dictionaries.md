# 1.3 Lists and dictionaries

## Concepts

- A list is an ordered sequence; a dict maps keys to values.
- A list of dicts is a common shape for a set of records.
- Access with `record["key"]`; loop with `for record in records:`.

## Commands / APIs

- `[]`, `{}`, `list.append(...)`, `dict["key"]`, `for ... in ...`
