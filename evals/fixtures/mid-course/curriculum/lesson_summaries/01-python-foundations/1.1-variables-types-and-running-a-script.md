# 1.1 Variables, types, and running a script

## Concepts

- Variables hold values; every value has a type (`str`, `int`, `float`, `bool`).
- `python file.py` runs a script from top to bottom.
- `print()` shows a value; f-strings interpolate variables into text.

## Commands / APIs

- `python script.py`
- `print(...)`, `f"{name}"`, `type(x)`

## What you built

- `workspace/greeting.py` — stores a name and an age, prints a sentence built from both.
