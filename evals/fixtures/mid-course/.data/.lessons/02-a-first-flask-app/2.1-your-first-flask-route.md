## Orient

New this lesson: the Flask application object, the `@app.route` decorator that
maps a URL path to a function, and running a dev server with `flask run`. Reused
from section 1: defining and returning from functions.

## Part 1 — The app object and a route

**Teach:** A Flask app is one `Flask(__name__)` object. A route is a normal
function with a `@app.route("/")` decorator on top; Flask calls it when someone
visits that path and sends whatever the function returns back to the browser.

**Show:**

```python
from flask import Flask

app = Flask(__name__)

@app.route("/")
def index():
    return "Hello!"
```

`@app.route("/")` — "run `index` for the site root". `return "Hello!"` — the
response body.

**Check:** In your own words, what does the `@app.route("/")` line do, and who
calls `index`?

## Part 2 — Returning real HTML and viewing it

**Teach:** The return value is just a string, so it can contain HTML tags. Start
the dev server with `flask run` (Flask finds `app.py` automatically), then open
the URL it prints.

**Show:**

```python
@app.route("/")
def index():
    return "<h1>Sam's Flask corner</h1><p>My first Flask app is running.</p>"
```

Then in the terminal:

```
flask run
```

Open `http://localhost:5000` in a browser — the `<h1>` and `<p>` render as a
heading and a paragraph.

**Check:** Before running it, predict exactly what the browser will display.
