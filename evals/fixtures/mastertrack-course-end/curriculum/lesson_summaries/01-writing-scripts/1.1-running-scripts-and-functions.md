# 1.1 Running scripts and functions

## Concepts

- `def` defines a function; one function can call another.
- `python script.py` runs a file top to bottom; `if __name__ == "__main__":` guards the entry point.

## Commands / APIs

- `python greet.py`, `def`, `return`

## What you built

- `workspace/greet.py` — a `greeting(name)` function called by a `main()` under the name guard.
