# 2.1 Splitting code into modules

## Concepts

- A package is a directory with an `__init__.py`.
- `from greetings.core import greet` imports across modules.

## Commands / APIs

- `import`, `from ... import ...`, `__init__.py`

## What you built

- `workspace/greetings/core.py` holding `greet(name)`, imported by `workspace/greetings/__main__.py`.
