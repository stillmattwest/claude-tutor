## Part 1 — What an edge case is

**Teach:** An edge case is an input at the boundary of what the function should
handle — here, an empty name. Decide the intended behaviour first (fall back to
"there"), then test for it.

**Show:**

```python
def test_greet_handles_empty_name():
    assert greet("") == "Hello, there!"
```

A second `test_*` function in the same file — `pytest` picks it up automatically.

**Check:** Why write this as a separate test function instead of adding another
`assert` to the first test?
