# Introduce Mastertrack

A **lesson-sized** post after the map exists. Show the roadmap, get them excited, and set mindset (patience, consistency). Then wait — do not start the first course in this turn.

Use only when `curriculum/MASTERTRACK.md` exists. If it does not, use `introduce-course` instead.

## Instructions

1. Read `curriculum/MASTERTRACK.md`, `.data/MASTERTRACK.md` if it exists, and `.data/STUDENT.md` if it exists. Use the name they asked you to use.
2. Deliver the introduction below. Split into **parts** if it would be a wall of text (same bar as `teach-lesson`). No code. Do not dump every start/end goal — a readable roadmap, one beat per map item.
3. **Stop.** Do not write `CURRICULUM.md`. Do not start C1. Wait until they say they are ready.

## Required shape (lesson-sized)

**Orient** — Welcome them onto this track by name. In a few sentences, what finishing it means in their words (the outcome they asked for), not a tool list.

**Roadmap** — Walk the map in order, in plain language:

- Each **curriculum** step: what they will be able to do when that course is done (the item end goal), not the lesson list.
- Each **milestone**: that they will build something from scratch (~a week) using what they just learned — no tutorial, you hint, they write.
- The **capstone**: ~2–3 weeks, the whole track, something they can point to.

Say the path is a sequence of full courses, not a survey. If the map has **Out of scope**, say it once in plain language (honest, not a scare). Name that the next thing, when they are ready, is the first course.

**Mindset** — Patience, consistency, and not rushing to the “real” topic. Progress is showing up and finishing the current step; shaky days are normal. Skipping foundations to go faster usually costs more time later.

Remind them that you are here to answer questions and mentor them every step of the way.

**Close** — Short spark: the first course is where the work starts, and it is enough. Ask if they want to begin that course (or change the remaining track with `adjust-mastertrack`). Wait.

## Do not

- Teach lesson 1.1 or write `CURRICULUM.md` in this turn.
- Repeat this full speech at the start of later courses (`introduce-course` handles that).
- Scare them, guarantee a job, or dump the raw map file.
- Use analogies; explain in plain language.

## Examples

- Map just written for professional web development → lesson-sized roadmap (Python, Postgres, build week, …, capstone), mindset, mentor reminder, wait to start C1.
- Student: “Remind me what this track is” → same skill; still do not start a course unless they ask.
