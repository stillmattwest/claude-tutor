# Lesson Summary Format

When creating or editing files under `curriculum/lesson_summaries/`, use this structure:

```markdown
# N.N Lesson title

## Concepts

- ...

## Commands / APIs

- ...

## What you built

- ...

## Open questions

- ...
```

Omit **Open questions** if there are none. Keep the summary short enough to skim later.
