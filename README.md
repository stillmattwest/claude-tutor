# cursor-tutor

Cursor Tutor is a collection of rules and skills that help Cursor to act as a curriculum designer and mentor for anything you want to learn to code.

## How to Use Cursor Tutor

Open a chat and invoke the curriculum skill (type `/curriculum`) and describe what you want to learn.

Example:

```
/curriculum I want to learn web development with Python and FastAPI
```

Cursor will ask you a few questions to understand your background and skill level, and then design a full curriculum divided into sections and lessons.

## Features

Curriculums follow a logical progression. Each section has a start point and a verifiable end goal.

Each section will contain multiple lessons, which also contain a start point and a verifiable end goal.

Frameworks and engines will not be treated as a black box. Cursor will explain them when they come up.

After each lessson, Cursor will quizz you about what you learned and correct you if necessary.

After each lesson, Cursor will write a lesson summary for you to refer back to. 


## Note:

This project is just getting started. Right now there is only one rule and one skill, but in my own testing the results have already been pretty good. 

Enjoy!
